# Beta Testing & Quality Assurance Readiness Checklist

**Application:** DigiPicture PictureBook Platform  
**Target Release:** Production Beta (v1.0.0-beta)  
**Date of Audit:** August 25, 2026

This checklist provides comprehensive quality assurance (QA), security smoke tests, rate-limiting verifications, error boundary recovery checks, and end-to-end user onboarding workflows prior to open public beta rollout.

---

## 1. Security & Authentication Smoke Tests

- [ ] **SEC-01: Password Hashing Verification**
  - **Action:** Register a new artist account with a strong password.
  - **Expected Result:** The password is transformed into a salted PBKDF2-SHA256 hash (10,000 iterations). Plaintext password is never stored or transmitted in plain logs.
  
- [ ] **SEC-02: Rate Limiter on Authentication**
  - **Action:** Trigger 6 rapid incorrect password attempts within 60 seconds.
  - **Expected Result:** The 6th attempt is blocked with a `"Too many login attempts. Please wait 1 minute."` notice.

- [ ] **SEC-03: Protected Route & RBAC Guards**
  - **Action:** As a Guest/Student Explorer, attempt to access Admin or verified Artist features.
  - **Expected Result:** Application prevents access, displays an unauthorized notice, and maintains student view safety.

- [ ] **SEC-04: Malicious Input & XSS Injection Sanitization**
  - **Action:** Submit a book title containing `<script>alert('xss')</script>` or `onload="evil()"`.
  - **Expected Result:** Zod validation schema and sanitization pipeline strip tags and escape special characters safely.

- [ ] **SEC-05: Sensitive Secrets & Key Masking**
  - **Action:** Inspect the browser console, network requests, and error logs.
  - **Expected Result:** Zero API keys, database secrets, or master passwords are exposed in the DOM or client logs.

---

## 2. Crash Reporting & Error Boundary Verification

- [ ] **ERR-01: Global Error Boundary Catch**
  - **Action:** Force a mock render fault or corrupted page object.
  - **Expected Result:** The app renders the child-friendly `ErrorBoundary` screen with recovery buttons (`Try Recovering View` / `Reload Application`).

- [ ] **ERR-02: PII Redaction in Error Logs**
  - **Action:** Verify logs generated by `errorMonitor.captureException()`.
  - **Expected Result:** Passwords, API keys (`AIzaSy...`), email tokens, and authorization tokens are redacted as `[REDACTED_...]`.

- [ ] **ERR-03: Network Disconnection Resilience**
  - **Action:** Simulate offline mode via browser DevTools while reading a curated book.
  - **Expected Result:** Story pages, interactive audio chimes, and illustrations remain accessible from local cache.

---

## 3. Legal, Privacy & Compliance Validation

- [ ] **LEG-01: COPPA Children's Privacy Mode**
  - **Action:** Explore picture books as a reader without logging in.
  - **Expected Result:** No PII or email address is requested. Reading bookmarks stay on the local device.

- [ ] **LEG-02: In-App Legal & Compliance Center**
  - **Action:** Click "Privacy (COPPA)", "Terms", "SDKs & APIs", or "Data Rights" in the footer or settings.
  - **Expected Result:** The `LegalComplianceModal` opens immediately with accurate policy terms, third-party declarations, and data export tools.

- [ ] **LEG-03: GDPR/CCPA Data Export (Portability)**
  - **Action:** Click "Download My Data (.JSON)" in the Compliance Center.
  - **Expected Result:** Browser initiates a download of the user's structured JSON data bundle.

- [ ] **LEG-04: Encrypted Vault Backup & Restore**
  - **Action:** Perform a point-in-time snapshot and encrypted `.vault` export via the Backup & Recovery utility.
  - **Expected Result:** AES-GCM-256 encrypted payload is generated and can be verified against integrity checksums.

---

## 4. Feature & User Onboarding Walkthrough

- [ ] **USR-01: First-Time Reader Onboarding**
  - **Action:** Launch the app with cleared storage.
  - **Expected Result:** The interactive welcome tutorial presents step-by-step guidance for story exploration, audio narration, and art discovery.

- [ ] **USR-02: Bilingual Language Switching**
  - **Action:** Switch between English (EN) and Swahili (SW) in the top header.
  - **Expected Result:** All UI labels, story text, and educational audio chimes instantly update.

- [ ] **USR-03: Artist Workbench Studio Flow**
  - **Action:** Create a custom 3-page picture storybook with the interactive drawing canvas and audio narration.
  - **Expected Result:** Artwork renders smoothly, pages save to state/Firestore, and the book appears in the creator's drafts/published shelf.

- [ ] **USR-04: Community Moderation & Safety Reports**
  - **Action:** Click "Report / Safety Desk" on a book and submit a constructive safety report.
  - **Expected Result:** The report is registered in the consolidated moderation queue for administrator review.

---

## 5. Performance & Device Compatibility

- [ ] **PERF-01: Responsive Layout on Mobile Viewports (320px - 768px)**
  - **Action:** Test on mobile screen sizes.
  - **Expected Result:** All touch targets are $\ge 44\text{px}$, buttons do not overflow, and reader controls are easily reachable.

- [ ] **PERF-02: Desktop & Tablet Viewports (1024px - 1920px)**
  - **Action:** Test on wide displays.
  - **Expected Result:** Book canvas scales responsively with high resolution and crisp vector typography.

- [ ] **PERF-03: Theme Switching (Daylight Warm / Twilight Night)**
  - **Action:** Toggle night mode from the header or settings.
  - **Expected Result:** Smooth color transition without flickering, meeting WCAG AA contrast standards.
